# Sunshine Study Room — Multi-page Demo

Pages:
- `/` Home
- `/book` Desk booking
- `/plans` Membership plans
- `/about` About + discussion room highlight

Plans:
- 1 Week — NPR 1,000
- 1 Month — NPR 3,000
- 6 Months — NPR 15,000
- 1 Year — NPR 28,000

Booking:
- 25 selectable study desks
- Demo reservations stored in browser localStorage
- Discussion room is presented as a separate feature, not a desk booking type

Run:
npm install
npm run dev
